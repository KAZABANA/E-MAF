# E-MAF
Official code of on-demand design of controlled-release systems using an expert-mimic AI framework

(1) Please install pandas, pygad, numpy, sklearn, scipy and the lightgbm using 'pip3 install xxx'

(2) Run the Expert-Mimic AI Framework.py to conduct the inverse design workflow using E-MAF.
     ** Please modify the root path before running the code. **
     
(3) A demo dataset derived from the literature is stored at "literature-derived subset.xlsx".
